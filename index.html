Prueba esto: guarda la curva con d = 2 mm, aumenta d a 8 mm y vuelve a cargar. Con las placas más separadas, C baja y el capacitor se llena más rápido. Con el circuito en pausa, si separas las placas el voltaje sube porque la carga no tiene a dónde ir.

C = ε₀·A / d
Carga: Vc = V₀(1 − e−t/RC)
Descarga: Vc = V₀·e−t/RC

Tipos de capacitores reales

Todos funcionan con el mismo principio, C = ε₀·κ·A / d: cambian el área de las placas, la distancia entre ellas y el material aislante (dieléctrico) que hay en medio.
